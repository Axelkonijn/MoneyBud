# Kintsugi's tables

Both are graded from CC0 textures on [Poly Haven](https://polyhaven.com), which need no credit and
may be used for anything; the credit is given anyway.

| File | Source | Author |
|---|---|---|
| `walnut.jpg` (dark) | [Black Walnut Veneer 02](https://polyhaven.com/a/black_walnut_veneer_02) | Jenelle van Heerden |
| `hinoki.jpg` (light) | [Okoume Veneer](https://polyhaven.com/a/okoume_veneer), graded toward hinoki | Jenelle van Heerden |

Graded from the 4k diffuse maps: turned a quarter so the grain runs along the phone, cropped to
1290 × 2800, coloured toward an oiled walnut or a pale hinoki, and darkened toward the edges.
