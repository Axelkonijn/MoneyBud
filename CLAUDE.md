# MoneyBud

A personal budgeting app — income, expenses, categories and savings goals for one person or
household. Hobby project. Public repo: https://github.com/Axelkonijn/MoneyBud

## Status

No application code yet. **The stack is deliberately undecided** — don't push toward requirements,
architecture or a first feature until asked.

## Working agreements

**Rhythm.** Agree the shape of a task up front, then run it to completion without stopping to check
in. Front-load the questions.

**Scope.** Take the literal ask, not the larger project implied behind it. When a request is
ambiguous about size, assume the smaller reading and confirm.

**`docs/` holds rough thinking**, not polished specs. Notes are meant to be messy and revisable;
something only becomes a real document once it has stopped changing.

**Decisions get their reasoning written down** — a few sentences on *why*, not a template. Applies
to choices that are annoying to reverse: stack, storage, how money is represented.

**This repo is public.** All example, seed and test data is synthetic. Real financial data,
account numbers and statements never enter the repo. `.gitignore` backs this up but isn't a
substitute for care.

**No license** by choice — all rights reserved for now. Don't add one unprompted.
